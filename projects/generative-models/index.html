01무엇을 공부했나

생성 모델이 데이터를 표현하고 새로운 샘플을 만드는 원리를 공부했습니다. 논문의 수식과 모델 구조를 읽고, 구현을 통해 각 구성 요소의 역할을 이해하는 데 집중했습니다.

02내가 한 일

  • VAE의 이론과 구현을 공부했습니다.
  • DDPM·DDIM·점수 기반 생성 모델의 구조와 수학적 기반을 분석했습니다.
  • Latent diffusion과 조건부 생성 방식을 살펴봤습니다.

03정리한 내용

생성 모델의 수학적 기반과 구현 방식을 정리했습니다. VAE·확산 모델의 논문 읽기와 구현 학습 경험을 쌓았습니다.
