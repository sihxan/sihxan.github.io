01무엇이 궁금했나

영상 속 작은 객체를 놓치는 이유는 시각 단서가 사라져서일까, 아니면 남아 있는 단서가 질문에 맞는 답변으로 이어지지 않아서일까? 실제 답변과 모델 내부에서 읽어낼 수 있는 정보를 같은 입력에서 비교했습니다.

02내가 맡은 일

  • 객체 크기·프레임 수·배경·질문을 나눈 통제 장면을 구성하고, Qwen 모델의 시각 처리 단계부터 답변 직전까지 내부 특징을 수집했습니다.
  • 내부 특징에서 정답을 읽는 별도 분류기를 학습하고, 배경 조합을 학습·검증·평가로 나눠 같은 평가 입력에서 원모델 답변과 비교했습니다.
  • 조건을 맞춘 내부 상태 교환과 대조를 구축했습니다. 원모델의 답변, 외부 분류기의 판독, 내부 상태를 바꾼 효과를 서로 다른 측정으로 구분해 분석했습니다.

03무엇을 확인했나

Qwen3.5-9B에 고정한 두 객체를 사용한 장면·질문 1,104조건을 평가했습니다. 같은 조건에서 답변 직전의 내부 특징을 읽는 학습된 외부 분류기는 874개, 원모델의 답변은 577개를 맞혔습니다.

이는 원모델이 틀린 일부 조건에서도 정답을 읽어낼 단서가 마지막 상태에 남는다는 진단 결과입니다. 외부 분류기를 학습한 비교이므로 원모델의 답변 성능을 개선한 결과와는 다릅니다. 1,104는 두 객체에서 만든 평가 조건 수이며, 독립된 자연 영상이나 서로 다른 제품의 개수가 아닙니다.

04지금 단계와 다음 질문

이 결과를 바탕으로 문맥·길이·질문에 따라 답변 계산이 달라지는 지점을 분석하고 있습니다. 다른 객체와 자연 장면에서도 같은 진단이 성립하는지, 실제 답변 개선으로 연결할 수 있는지를 별도로 검증해야 합니다.
