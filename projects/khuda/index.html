01어떤 프로젝트였나

경희대학교 데이터 분석 동아리 KHUDA에서 머신러닝·딥러닝 기초를 공부하고, 추천 시스템과 자연어 처리 프로젝트를 진행했습니다.

02내가 한 일

  • 추천 시스템 프로젝트에서 도서 추천 시스템을 구현했습니다.
  • 자연어 처리 프로젝트에서 욕설을 탐지하고 마스킹하는 기능을 구현했습니다.
  • 머신러닝·딥러닝의 기초 개념을 학습했습니다.

03구현한 것

도서 추천 시스템과 욕설 탐지·마스킹 기능을 구현하며, 추천과 텍스트 처리 문제를 프로젝트로 경험했습니다.
