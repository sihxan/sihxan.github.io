가상 피팅의 실행 흐름을 정리하고, 외부 API가 맡던 핏 지시문 생성을 로컬 VLM으로 옮겼습니다.

Rewake / Sunicon 산학협력 · 2026.09–10 구현·검증 자료 기준
무엇을 해결하려 했나내가 맡은 일결과와 산출물검증 범위와 남은 점

01무엇을 해결하려 했나

제품 사진과 착용 참조에서 의상의 길이·핏을 읽고, 이를 이미지 생성에 전달하는 흐름이 필요했습니다. 실험 코드를 다른 환경에서도 실행할 수 있도록 입력·설정·출력을 연결하는 일도 맡았습니다.

02내가 맡은 일

  • 모델컷 생성과 가상 피팅의 실행 설정을 정리하고, 전처리 → 핏 측정 → 지시문 → 이미지 생성 단계를 연결했습니다.
  • 핏 지시문 단계를 로컬 VLM으로 교체하고, vLLM·FP8 추론, JSON 검증·재시도, 추론 길이 제어를 구현했습니다.
  • 입력 해시·실행 조건·실패 기록을 남기고, 단일 GPU에서 서버 기동·종료와 단계별 실행을 관리하는 배치 흐름을 구성했습니다.

03결과와 산출물

전달용 코드·실행 설정·사용 가이드를 만들었습니다. 로컬 핏 지시문 생성부터 가상 피팅 이미지 생성까지 단일 GPU에서 순차 실행하는 경로를 확인했습니다.

추론 속도·메모리 사용·출력 오류를 비교한 기록을 남겼습니다. 정상 종료와 실패·중단 시 서버 정리 동작도 확인했습니다.

04검증 범위와 남은 점

검증은 일부 상의 사례를 대상으로 했습니다. JSON 형식이 올바른 경우에도 의상 길이·핏을 잘못 읽는 사례가 남아, 지시문의 정확성과 최종 이미지 품질을 따로 확인해야 합니다.
