연구 · 오프라인 실험

영상 모델의 KV-cache 압축

영상 모델이 기억해 둔 정보를 더 작은 메모리에 담는 방법을 연구합니다. 압축·복원 코드를 구현하고, 저장량이 줄어드는 것과 모델 계산이 유지되는 것을 따로 확인했습니다.

맡은 일
압축 표현·독립 복원기 구현, 비교 실험 구성, 층·헤드별 오차 분석
현재 단계
오프라인 구현·비교 결과 확보 · 질문 정답률과 전체 추론 속도는 후속 평가
무엇을 알아보려 했나맡은 일확인한 결과다음 검증

01무엇을 알아보려 했나

긴 영상을 처리하면 모델이 보관하는 중간 정보인 KV-cache도 커집니다. 미래에 어떤 질문이 들어올지 모르는 상태에서, 제한된 메모리 안에 필요한 정보를 얼마나 남길 수 있는지가 연구 질문입니다.

압축한 데이터를 원본처럼 복원하는 것만으로는 충분하지 않습니다. 복원된 정보로 모델이 계산한 attention 출력까지 비교해야 압축의 영향을 알 수 있습니다.

02맡은 일

  • Qwen2.5-VL에서 수집한 실제 KV로 저비트 양자화, 평균·잔차 공유, 학습형 압축기를 비교했습니다.
  • 압축 파일과 별도의 복원기를 구현해, 메타데이터를 포함한 실제 저장량과 복원 결과를 함께 검사했습니다.
  • 저장량·KV 복원 오차·attention 출력 오차를 분리해 측정했습니다. 학습형 비교에서는 5개 층, 3개 잠재 차원, 2개 시드와 두 구조를 조합한 60개 설정을 학습했습니다.

03확인한 결과

학습형 압축 실험에서 KV 복원 오차가 작아져도 attention 출력 오차는 커질 수 있음을 확인했습니다. 압축 데이터가 원본과 비슷하다는 사실이 모델 계산의 보존을 보장하지는 않았습니다.

  • 별도의 12개 영상 비교에서도 저장량과 attention 오차의 우열이 조건에 따라 달랐습니다. 추가 구조를 사용하는 압축 방식이 모든 조건에서 유리하지는 않았습니다.
  • 1개 영상·2개 층의 실제 파일 검증에서는 10개 비교 파일 모두 바이트 상한과 독립 복원 검사를 통과했습니다. 추가 잔차 선택 기능은 이 두 조건에서 선택되지 않았고, 품질 이득 없이 계산 비용을 더했습니다.
확인한 수치와 평가 범위
구분수치조건
영상 비교 패널12수집 영상의 층·헤드별 저장량·attention 비교. 학습형 실험과 별도 구성입니다.
학습한 압축기 설정605개 층 × 3개 잠재 차원 × 2개 시드 × 2개 구조. 학습형 실험은 총 13개 영상을 학습·검증·탐색 평가·참조로 분리했습니다.

04다음 검증

현재 결과는 저장된 KV를 이용한 오프라인 압축·수치 검증입니다. 12개 영상 비교와 학습형 압축 실험은 서로 다른 평가 구성으로, 하나의 성능 수치로 합치지 않았습니다.

앞으로는 압축한 상태에서 미래 질문의 정답률, 전체 추론 시간과 GPU 메모리를 평가해야 합니다. 이를 위해 기본 모델의 수치 차이를 먼저 분리하고, 같은 메모리 예산의 비교 기준을 유지할 계획입니다.
