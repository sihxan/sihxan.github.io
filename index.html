딥러닝 연구AI 서비스 개발

딥러닝을 연구하고,
AI 서비스를 개발합니다.

경희대학교 KDST Lab 학부연구생으로 작은 객체 인식과 영상 모델의 KV-cache 압축을 연구합니다. 가상 피팅 파이프라인과 RAG 서비스 개발 경험이 있습니다.

연구와 프로젝트

01연구 · 원고 작성

CLIP의 작은 객체 판별

작은 객체와 주변 문맥의 역할 비교

맡은 일: 객체 영역을 가리거나 다른 이미지에 옮기는 대조 실험을 설계·분석했습니다.

결과: 객체 영역 밖에도 판별 단서가 남는 조건을 확인했고, KSC 2026 제1저자 원고를 작성 중입니다.

CLIP · 가림·이식 실험

02연구 · 진행 중

작은 객체와 VideoLLM

모델 내부 정보와 실제 답변 비교

맡은 일: 객체 크기와 배경을 통제하고, 내부 정보로 학습한 분류기와 모델의 실제 답변을 비교했습니다.

결과: 두 객체의 합성 실험에서 동일한 1,104조건 중 분류기는 874개, 모델 답변은 577개를 맞혔습니다.

VideoLLM · 내부 상태 분석

03연구 · 오프라인 실험

영상 모델의 KV-cache 압축

메모리 압축이 모델 계산에 미치는 영향

맡은 일: 영상 모델의 메모리 압축·복원 코드를 구현하고, 저장량과 계산 오차를 비교했습니다.

결과: 오프라인 실험에서 복원 오차가 줄어도 attention 출력 오차는 커질 수 있음을 확인했습니다.

KV-cache · 압축·복원 · 오프라인 평가

04산학협력 · 파이프라인 개발

모델컷 생성·가상 피팅

가상 피팅을 실행·전달 가능한 코드로

맡은 일: Rewake / Sunicon 산학협력에서 가상 피팅 실행 흐름을 정리하고, 핏 지시문 생성을 로컬 VLM으로 교체했습니다.

산출물: 단일 GPU 순차 실행을 확인하고, 전달용 코드·설정·사용 가이드를 제작했습니다.

VTON · 로컬 VLM · 실행·인수인계

05연구 설계

데이터 증류와 선택 편향

작은 데이터셋에서도 소수 그룹을 보존

맡은 일: 데이터 선택 편향을 검토하고, 소수 그룹을 보존하는 샘플 선택 방식을 설계했습니다.

산출물: SAMBA 설계와 그룹별 평가 기준을 마련했으며, 구현·성능 평가는 후속 단계입니다.

데이터 증류 · 그룹별 평가

06서비스 개발

Allmize AI 서비스 개발

RAG와 AI 기능 개발

맡은 일: Allmize 초기 멤버로 RAG 워크플로와 AI 기능 개발에 참여했습니다.

산출물: 애플리케이션 로직을 구현하고, 제품·기술 개선안을 제안했습니다.

RAG · AI 서비스

07논문 읽기·구현

생성 모델 논문 읽기·구현

생성 모델의 수식을 코드로 확인

맡은 일: 생성 모델 논문을 읽고, 주요 수식과 동작을 코드로 확인했습니다.

산출물: VAE·DDPM·DDIM을 구현하며 잠재 공간과 확산 과정을 익혔습니다.

VAE · DDPM · DDIM

2025.11 — 현재

KDST Lab

학부연구생

경희대학교 딥러닝 연구실

  • CLIP·VideoLLM의 작은 객체 인식과 KV-cache 압축을 연구하며, 조건을 통제한 실험·내부 특징 수집·오차 분석 코드를 구축합니다.
  • 작은 객체의 bbox·문맥 기여 실험을 KSC 2026 제1저자 원고로 정리하고, Rewake / Sunicon 산학협력에서는 가상 피팅 실행 흐름과 로컬 VLM 추론 경로를 개발했습니다.
  • 논문 읽기 모임을 운영하고 멀티모달 스터디에 참여하며, 연구실 세미나에서 구현과 실험 내용을 논의합니다.
